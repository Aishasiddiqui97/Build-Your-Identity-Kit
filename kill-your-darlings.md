## 3. AI Image Generation Prompt (Reusable)

```
A minimalist futuristic abstract background, dark midnight plum (#1E0A3C) to deep teal (#0D4F4F) gradient, thin luminous gold (#D4AF37) geometric lines and subtle grid patterns, no text no screens no UI no figures, atmospheric soft glow, 8K resolution, matte finish, clean tech aesthetic, wide angle, subtle vignette, --ar 16:9 --no text --no people --no screens --no icons --no letters
```

**Why this works:** It produces consistent, brand-locked backgrounds across all supporting slots. The `--no` flags enforce purity — no fake UIs, no fake code, no generic robots. Every generated image stays behind the content, never pretending to be the content.
